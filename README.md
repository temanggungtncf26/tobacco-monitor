## Langkah Deploy

### 1. Update Google Apps Script (code.gs)

1. Buka [script.google.com](https://script.google.com) → proyek Anda
2. **Ganti seluruh isi** `code.gs` dengan file `code.gs` baru ini
3. Klik **Deploy → Manage Deployments → Edit (✏️)**
4. Pilih **New Version** → klik **Deploy**
5. Salin URL deployment (tidak berubah jika edit versi lama)

> ⚠️ Pastikan URL di `index.html` pada variabel `GAS_API_URL` sudah sesuai dengan URL deployment Anda.

---

### 2. Deploy Frontend ke GitHub Pages (Gratis)

**a. Buat repository baru di GitHub**

```
Nama repo: tobacco-monitor  (atau nama lain)
Visibility: Public (wajib untuk GitHub Pages gratis)
```

**b. Upload semua file** (kecuali `code.gs` dan `README.md` tidak wajib):

```
index.html
manifest.json
service-worker.js
icons/  (folder beserta isinya)
```

**c. Aktifkan GitHub Pages:**

```
Settings → Pages → Source: Deploy from branch
Branch: main → Folder: / (root) → Save
```

**d. Tunggu 1-2 menit**, URL app Anda:

```
https://<username>.github.io/<nama-repo>/
```

---

### 3. Install App ke HP (PWA)

**Android (Chrome):**
- Buka URL GitHub Pages di Chrome
- Tap ikon ⋮ → "Add to Home screen" / "Install app"

**iPhone (Safari):**
- Buka URL di Safari
- Tap ikon Share (kotak + panah) → "Add to Home Screen"

## Cara Kerja Offline

| Kondisi | Perilaku |
|---|---|
| Online | Fetch data langsung dari GAS, cache aset statis |
| Offline pertama buka | Tampil UI shell dari cache |
| Offline saat fetch data | Muncul notifikasi "Tidak ada koneksi internet" |
| Kembali online | Data langsung bisa diambil kembali |

## Troubleshooting

### "Gagal memuat data" saat login pertama
→ Pastikan `code.gs` sudah di-deploy ulang dengan versi baru (yang ada `doPost`)

### CORS error di browser
→ GAS `doPost` dengan `Content-Type: text/plain` tidak memerlukan preflight.
Jika masih error, cek bahwa deployment GAS di-set ke **"Anyone"** (bukan hanya pengguna organisasi)

### Service Worker tidak terupdate
→ Ubah `CACHE_VERSION` di `service-worker.js` (misal: `tobacco-monitor-v2`) lalu push ulang

### Icon tidak muncul di layar HP
→ Pastikan folder `icons/` ter-upload dan path di `manifest.json` sudah benar

## Catatan Keamanan

- Session token disimpan di **memori JS** saja (bukan localStorage/cookie), aman dari XSS persisten
- Semua request ke GAS melalui HTTPS
- `doPost` hanya mengizinkan fungsi yang ada di `allowedActions`
